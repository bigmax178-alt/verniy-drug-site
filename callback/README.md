# Мгновенное обновление сайта по событиям ВКонтакте

По умолчанию сайт пересобирается каждые 30 минут (см. `.github/workflows/sync-and-deploy.yml`).
Чтобы новый пост появлялся на сайте через минуту-две, подключите Callback API группы.

## 1. Разверните воркер (5 минут, бесплатно)

1. Зарегистрируйтесь на cloudflare.com → Workers & Pages → Create Worker.
2. Вставьте код из `vk-callback-worker.js`, нажмите Deploy. Скопируйте адрес вида `https://vk-callback.<имя>.workers.dev`.
3. В Settings → Variables добавьте секреты:
   - `VK_CONFIRMATION` — из VK (см. ниже, шаг 2.2)
   - `VK_SECRET` — придумайте любую строку
   - `GITHUB_TOKEN` — GitHub → Settings → Developer settings → Fine-grained tokens → доступ к репозиторию сайта, права **Contents: Read and write**
   - `GITHUB_REPO` — `владелец/репозиторий`

## 2. Настройте Callback API в группе

1. Управление сообществом → Работа с API → Callback API → «Добавить сервер».
2. Укажите адрес воркера, скопируйте «Строку, которую должен вернуть сервер» в переменную `VK_CONFIRMATION`, нажмите «Подтвердить».
3. Секретный ключ — тот же, что `VK_SECRET`.
4. Вкладка «Типы событий»: отметьте
   - Записи на стене: добавление, редактирование, удаление, репост
   - Товары: добавление, редактирование, удаление
   - Обсуждения: новое сообщение, редактирование
   - Фотографии: добавление

Готово: любое из этих событий запускает `repository_dispatch: vk-update`, а GitHub Actions пересобирает и публикует сайт.
